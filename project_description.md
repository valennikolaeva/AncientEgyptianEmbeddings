## Аннотация

## Аннотация

Проект посвящён применению современных многоязычных эмбеддинговых моделей к древнеегипетскому языку — мёртвому языку с историей письменности более 3000 лет, отсутствием живых носителей и экстремальной полисемией. Одна лемма может иметь до 14 различных значений, а корпус доступен только через специализированные аннотированные базы данных. Стандартные многоязычные модели никогда не видели египетского текста, что делает их прямое применение неэффективным.

Ключевая идея работы — кросс-язычный трансфер: вместо того чтобы обучать модель с нуля, мы используем немецкие переводы египетских текстов как семантический мост. Параллельный корпус из 91k пар египетский–немецкий из Thesaurus Linguae Aegyptiae (TLA) позволяет адаптировать многоязычный энкодер SONAR (Meta, 766M параметров) к языку, которого он никогда не видел, опираясь на уже выученные представления немецкого.

Обучение проходило в три этапа. На первом этапе модель выравнивала египетские и немецкие предложения в общем семантическом пространстве через контрастивный лосс. На втором этапе triplet loss с маскированием целевого слова учил модель различать значения полисемичных лемм по контексту. На третьем этапе curriculum learning с hard negative mining — постепенное усложнение задачи от лёгких негативов к трудным — предотвращало representation collapse, который неизбежно возникал при прямом обучении на сложных примерах.

На бенчмарке Word Sense Induction (WSI) с экспертной разметкой из TLA модель достигает ARI = 0.79 для слова *bj* и ARI = 0.32 для *bnj*, превосходя как базовый SONAR, так и Qwen3-8B (8B параметров) без дообучения. Это подтверждает главный вывод: доменная адаптация важнее размера модели. На расширенном наборе из 395 сбалансированных слов лучшие результаты достигают ARI = 0.62.

Помимо WSI, проект включает анализ семантического сдвига слов во времени. Cosine similarity между центроидами слов nswt («царь») и pr-ꜥꜣ («фараон») превышает 0.94 во все восемь исторических периодов от Древнего царства до греко-римской эпохи. Это первое количественное свидетельство гипотезы египтологов о семантическом вытеснении — pr-ꜥꜣ не создало новую семантическую нишу, а вошло в уже занятую.

Практическая ценность работы выходит за рамки древнеегипетского. Предложенная методология применима к любому языку с параллельным корпусом к высокоресурсному языку — аккадскому, шумерскому, коптскому. Модель открывает возможности для семантического поиска по TLA (поиск похожих сцен по смыслу, а не по ключевым словам) и количественного анализа семантических изменений в заупокойной литературе на протяжении тысячелетий.

## Проблематика

Древнеегипетский язык обладает экстремальной полисемией: одна лемма может иметь 14+ различных значений (например, *pr* — дом, храм, гробница, сосуд, выход, зима и др.). Существующие методы WSI для древних языков опираются либо на ручную аннотацию (GASC, EDiSC), либо на байесовские модели, которые плохо справляются с разреженными данными. Современные многоязычные модели (mBERT, LaBSE, SONAR) не видели египетского текста в процессе предобучения, что делает прямое применение неэффективным.

При этом египтологи тратят годы на ручной анализ семантических паттернов в корпусе Thesaurus Linguae Aegyptiae (TLA), насчитывающем более 100k аннотированных предложений. Автоматические инструменты для навигации по корпусу и анализа семантических изменений практически отсутствуют.

## Постановка задачи

**Исследовательский вопрос:** можно ли адаптировать современный многоязычный энкодер к мёртвому языку через кросс-язычный трансфер, используя параллельные переводы как семантический мост?

**Задача 1 — Word Sense Induction:** различать значения полисемичных лемм в контексте (например, *sḏm* = «слышать» vs «слуга» vs «слышание»).

**Задача 2 — Diachronic Semantic Shift:** отслеживать изменение семантики слов на протяжении исторических периодов (Древнее царство → греко-римская эпоха).

**Ground truth:** экспертные аннотации lemma_id из TLA — уникальные идентификаторы словарных значений, присвоенные египтологами.

---

## Техническое решение

**Данные:** 101,785 параллельных пар египетский–немецкий из TLA (73k train / 9k val / 9k test).

**Трёхэтапный пайплайн:**

1. **Stage 1 — Contrastive Alignment.** Дообучение SONAR на парах египетский↔немецкий через MultipleNegativesRankingLoss. Египетские предложения с градиентами, немецкие заморожены как anchor. Val loss: 1.84 → 0.07 за 6 эпох.

2. **Stage 2 — Triplet Loss для WSI.** Построение триплетов из lemma_id аннотаций: anchor и positive — одно значение, negative — другое значение того же слова. Целевое слово маскируется перед кодированием — модель вынуждена опираться на контекст.

3. **Stage 3 — Curriculum Learning.** Трёхфазное обучение: easy negatives (другое слово) → medium (случайный негатив того же слова) → hard (ближайший сосед из другого класса). Регуляризация против representation collapse. Снижение доли нарушенных триплетов с 90% до 62%.

**Стратегии эмбеддинга:** plain (полное предложение), masked (без целевого слова), window (±3 слова). Лучшая стратегия выбирается автоматически.

## Результаты

**WSI (ARI, лучшая стратегия):**

| Слово | Значений | SONAR base | LaBSE ft | SONAR Curriculum | Qwen3-8B |
|-------|----------|-----------|---------|-----------------|---------|
| bj    | 2        | 0.061     | 0.038   | **0.788**       | —       |
| bnj   | 4        | 0.020     | 0.079   | **0.323**       | 0.191   |
| ꜥnḫ  | 11       | 0.008     | 0.010   | **0.069**       | 0.025   |
| sḏm   | 3        | 0.048     | 0.026   | 0.022           | 0.007   |

**Ключевые выводы:**
- Curriculum learning необходим: прямое обучение на hard negatives приводит к коллапсу (std < 0.003).
- SONAR (766M) после дообучения превосходит Qwen3-8B (8B) — доменная адаптация важнее размера.
- Cosine similarity между nswt («царь») и pr-ꜥꜣ («фараон») > 0.94 во все 8 исторических периодов, включая Древнее царство (0.97) — первое количественное подтверждение гипотезы о семантическом вытеснении.
- На расширенном наборе из 395 сбалансированных слов лучшие результаты: ḥm-kꜣ ARI = 0.52, hꜣb ARI = 0.62.

**Ограничения:** sentence-level эмбеддинги теряют токен-уровневую информацию; для слов с многими значениями и несбалансированными классами ARI остаётся низким.

## Дальнейшие планы

- **mmBERT + DAPT:** дообучить mmBERT на египетском корпусе через MLM для токен-уровневых эмбеддингов и сравнить с SONAR.
- **Семантическая эволюция слов:** применить метод к словам nm.t, ḥtm из статьи научника для количественного подтверждения его гипотез о semantic drift в заупокойной литературе.
- **Семантический поиск по TLA:** разработать инструмент для египтологов — поиск похожих сцен и мифологических ситуаций по смыслу, а не по ключевым словам.
